# Database Users and Environment

## 1. Database Users

Different people interact with a database in different ways.

### Database Administrator (DBA)

The **DBA** is responsible for managing and controlling the database system.

Main responsibilities:

* Database security
* User access control
* Backup and recovery
* Performance monitoring
* Database maintenance
* Storage management

### Database Designers

Design the database structure, including:

* Tables
* Relationships
* Constraints
* Data models

### Application Programmers

Develop applications that interact with the database.

### End Users

Use database applications to access information.

Examples:

* Bank customers
* Students
* Employees
* Hospital staff

---

## 2. Database System Environment

A database system environment consists of:

```text
Users
  ↓
Applications
  ↓
DBMS
  ↓
Database
```

It may also include:

* Hardware
* Software
* Database
* Procedures
* Users

---

## 3. Main Role of the DBA

```text
Database
   ↑
   |
  DBA
   |
   ↓
Security + Backup + Recovery + Performance
```

---

## Key Takeaway

> The **DBA manages the database**, while designers, programmers, and end users interact with it according to their roles.
